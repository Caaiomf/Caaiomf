## Projetos em destaque

### PiNativus - Mercado online com Node.js e Express

Sistema web didatico inspirado em um mercado de produtos naturais, com fluxo de cliente e funcionario.

**Principais recursos:**

- Loja com vitrine de produtos
- Cadastro e login de usuarios
- Controle de acesso por sessao
- Carrinho de compras
- Checkout com forma de entrega, pagamento e cupom
- Area de funcionario
- Cadastro, listagem e remocao de produtos
- Upload de imagens com Multer
- Cookies para ultimo acesso
- Persistencia simples em arquivo JSON
- Organizacao em pastas para paginas, dados, sessoes e utilitarios

**Tecnologias:** Node.js, Express, JavaScript, Bootstrap, HTML, CSS, Cookie Parser, Express Session, Multer, JSON, Vercel.

### Portfolio de Arquitetura - Site com painel administrativo

Portfolio frontend para apresentar projetos de arquitetura e urbanismo com layout responsivo, filtros por categoria, galeria em modal e area administrativa local.

**Principais recursos:**

- Pagina publica responsiva
- Hero com projeto em destaque
- Filtros por categoria
- Galeria de imagens em modal
- Formulario com integracao para WhatsApp
- SEO tecnico com meta tags, Open Graph, manifest e JSON-LD
- Painel administrativo com login
- Cadastro de projetos
- Upload de imagens
- Script para gerar dados dos projetos automaticamente
- Revisao visual com Playwright

**Tecnologias:** HTML, CSS, JavaScript, Node.js, Express, Multer, Playwright, JSON, SEO tecnico.
